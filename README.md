## El proyecto

El portfolio está construido como una página estática con:

- **Astro 7** para la estructura y el renderizado;
- **Tailwind CSS 4** para los estilos;
- **Vite+** para los comandos de desarrollo y build;
- componentes Astro pequeños y enfocados;
- una estética editorial oscura, con transiciones suaves y foco en el contenido.

La paleta visual está documentada en [`docs/color-palette.md`](docs/color-palette.md).

## Desarrollo local

Requiere **Node.js 22.12 o superior**.

```bash
npm install
npm run dev
```

Luego abrí [http://localhost:4321](http://localhost:4321).

Para generar una build de producción:

```bash
npm run build
```

También están disponibles los comandos equivalentes con Vite+:

```bash
npm run vp:dev
npm run vp:build
```
