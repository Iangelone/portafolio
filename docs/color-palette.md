# Paleta de colores

Paleta base del portafolio, ordenada de más oscuro a más claro.

| Token | Hex | Uso sugerido |
| --- | --- | --- |
| `ink-950` | `#111111` | Fondo principal |
| `ink-925` | `#101010` | Fondo alternativo |
| `ink-900` | `#121212` | Superficie profunda |
| `ink-850` | `#161616` | Superficie secundaria |
| `ink-800` | `#191919` | Cards oscuras |
| `ink-750` | `#1A1A1A` | Cards elevadas |
| `ink-700` | `#1C1C1C` | Inputs y controles |
| `ink-650` | `#1E1E1E` | Hover sutil |
| `ink-600` | `#202020` | Superficie activa |
| `ink-500` | `#2B2B2B` | Bordes fuertes |
| `ink-400` | `#2C2C2C` | Bordes y divisores |
| `ink-300` | `#2F2F2F` | Elementos destacados |

## Principios de uso

- Usar `#111111` como fondo dominante.
- Reservar `#2B2B2B` a `#2F2F2F` para bordes, divisores y estados activos.
- Mantener suficiente contraste con texto claro y acentos de marca.

## Colores de acentuación

| Token | Hex | Uso sugerido |
| --- | --- | --- |
| `accent-brown-dark` | `#1F150C` | Fondos cálidos y bloques de contacto |
| `accent-brown` | `#412D15` | Bordes, divisores y detalles |
| `accent-cream` | `#E1DCC9` | CTA, enlaces y títulos de sección |
